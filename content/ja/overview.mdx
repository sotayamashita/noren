Showcase はエージェントが変更したファイルを読み、短いテスト計画に変換し、Playwright で本物のブラウザ上で実行します。失敗は推測ではなく実行時の証拠としてエージェントに返ります。失敗したリクエスト、コンソールのエラー、スクリーンショットです。

### 検証する内容

- **フロー**: 差分が触れたページを、ログイン済みユーザーとして操作します。
- **ネットワーク**: 失敗したリクエスト、遅いエンドポイント、欠けたメタデータ。
- **回帰**: 新しい計画の前に、前回の計画を再実行します。

### 実行方法

```bash
npx -y showcase@latest init
```

続けて、エージェントの中で次を実行します。

```text
/showcase test the signup flow
```

| フラグ     | 効果                                                |
| ---------- | --------------------------------------------------- |
| `--ci`     | ヘッドレス実行、計画を自動承認、30 分でタイムアウト |
| `--headed` | 実行中のブラウザを表示                              |
