Showcase reads the files your agent changed, turns them into a short test plan, and runs that plan in a real browser with Playwright. Failures are reported back to the agent as runtime evidence: the request that failed, the console error, the screenshot.

## How it works

### What it checks

- **Flows**: the pages touched by the diff, driven like a logged-in user.
- **Network**: failing requests, slow endpoints, missing metadata.
- **Regressions**: the previous plan is replayed before the new one.

### Running it

```bash
npx -y showcase@latest init
```

Then, inside your agent:

```text
/showcase test the signup flow
```

| Flag       | Effect                                             |
| ---------- | -------------------------------------------------- |
| `--ci`     | Headless, auto-approve the plan, 30 minute timeout |
| `--headed` | Watch the browser while it runs                    |
