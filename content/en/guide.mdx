## FAQ

<Faq>
  <FaqItem question="Can I deploy somewhere other than Vercel?">

Yes. It is a plain Next.js app, so it runs on Cloudflare, Netlify, your own Node server or any other host that runs Next.js. After `just build`, `just start` serves the production build. Static export is not supported, because locale routing and the Open Graph image are generated on the server.

  </FaqItem>
  <FaqItem question="Can I add languages beyond English and Japanese?">

Yes. Add a locale and put that language's `site.json`, `guide.mdx` and `demo.ts` in `content/`. The steps are in AGENTS.md, so asking your agent to add a language is enough.

  </FaqItem>
  <FaqItem question="What is the license? Can I use it for a commercial product?">

MIT. Use it for a commercial product's page as it is. Agentation, used only during development, is a <Link href="https://github.com/benjitaylor/agentation/blob/main/LICENSE">PolyForm Shield package</Link> and is not part of the production build.

  </FaqItem>
</Faq>
